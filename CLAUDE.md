### Project overview
Application where I can see my to do task integrated with obsidian. It also shows me pomodoro timer and music which I can choose. It also register my focus session where I can check how many times I got distracted or not. Integration with spotify/youtube and custom music from disc

### Stack
- React 19
- TypeScript 
- Electron 41
- Tailwind 4
- Vite
- Vitest 3
- shadcn
- SQLite
- fs + gray-matter

### Commands
`npm run lint` - Check the status of code there is any errors (use it before writing me what you did
`npm run dev` - running development server use it when you need to check things are place right
`npm run build` - building application for real one
`npm run test` - Run test make sure every test will pass it
